**Smart Monitoring System for Pet and Plant Care**

*Project Overview*

The *Smart Monitoring System for Pet and Plant Care* is an IoT-based project designed to help users monitor their plants and pets when they are away from home.

The system collects real-time information using sensors and displays the data on a website.

*What It Monitors*

The system monitors:

1) 🌡️ Temperature
2) 💧 Humidity
3) 🌱 Soil moisture
4) 💡 Light level
5) 🐾 Pet movement

*Main Components*

The project uses:

1) **NodeMCU-V3** – the main microcontroller
2) **DHT11** – measures temperature and humidity
3) **Soil Moisture Sensor** – checks soil moisture
4) **PIR Motion Sensor** – detects movement
5) **LDR** – measures light intensity

The NodeMCU collects the sensor data and sends it to a website using Wi-Fi.

*Project Goal*

The main goal is to make monitoring plants and pets easier by providing **real-time environmental information** and reducing the need for frequent manual checks.

*Project Scope*

This project focuses on **monitoring and reporting**. It does not automatically water plants or feed pets.
